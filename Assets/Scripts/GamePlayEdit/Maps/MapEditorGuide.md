# 맵 편집기

메뉴: **Tools > EverWind > Map Editor**

1. **새 작업 씬**은 기존 씬을 닫고 단독 작업 씬을 연다. 미저장 변경이 있으면 Unity 저장 확인에서 저장/취소를 선택할 수 있다. `Common/DefaultMap.prefab`의 월드·조명·하늘을 자동 배치하고 Terrain을 Land에 연결한다. **작업 씬 저장**으로 보관하며, 나중에 씬을 열고 맵 루트를 선택한 뒤 **선택한 맵 사용**을 누른다.
2. 기본 월드에는 바로 편집·추출할 수 있는 연속 지면 영역을 자동 설정한다. 영역은 필요에 따라 넓힐 수 있다. 다른 지면을 사용하려면 Hierarchy에 드래그한 뒤 Land 참조를 지정한다. Land에는 보행 지면 Collider만 포함하고 건물·장애물은 Geometry나 일반 배치물에 둔다.
3. 맵 ID·중심·반경·플레이어 스폰을 지정한다. **Land 기준 높이 영역 자동 설정** 후 격자 영역을 확인한다. 영역의 모든 격자점이 Land 위에 있어야 하며 지면 구멍이 있으면 추출을 중단한다. 격자 간격을 줄이면 곡면의 서버 높이 보간 정밀도가 올라간다.
4. Project의 `Maps/Props`에서 원하는 프리팹을 Scene 뷰의 Land 위로 드래그앤드롭한다. 용도/정의 ID/높이 보정/리스폰 설정은 프리팹 MapPlacement 값을 복사한다. 용도는 맵 편집기에서 읽기 전용이며 변경하려면 원본 프리팹의 MapPlacement를 편집한다. 클릭 배치·선택 오브젝트 수동 등록·프리팹 가져오기·목록 선택 UI는 제공하지 않는다. **모든 배치물 Land 높이 맞춤** 버튼은 유지한다.
5. 이동·회전·크기 조절은 기본 Scene 도구를 사용한다. 배치 및 Scene 이동 종료 시 지면 높이를 맞추며 추출 시에도 다시 보정한다. 모델 바닥 기준 정렬을 끄면 피벗을 Land에 맞춘다. 추가 높이 보정으로 에셋 피벗 차이를 조절한다. 스폰 개체 ID는 맵 안에서 유일해야 한다. 복제한 배치물의 중복 ID는 직접 변경한다.
6. **애니메이션·파티클 미리보기**는 편집 모드에서 Idle 클립(없으면 첫 클립)과 파티클을 재생한다. 중지·창 닫기·Play Mode 진입·추출 시 종료한다. 서버 AI·전투·물리 플레이 시뮬레이션은 아니다.
7. Maps 하위 새 폴더명을 정하고 **서버 TXT 위치 선택 후 추출**을 누른다. TXT와 고유 이름의 `.heights`를 같은 디렉터리에 저장한다. 프리팹은 `Assets/Scripts/GamePlayEdit/Maps/<지정 이름>/Map<ID>Visual.prefab`에 생성하며 기존 폴더와 겹치면 새 이름을 사용한다. 서버에는 TXT와 그 안에서 참조하는 높이 파일을 함께 전달한다.

맵 루트는 위치0/회전0/크기1을 유지하고 자식을 편집한다. 스폰 위치의 Y는 서버 높이 격자로 결정한다. TXT에는 현재 서버 계약대로 XZ와 정의 ID를 기록한다. 몬스터·채집물 미리보기는 클라이언트 맵 프리팹에서 제외한다. 일반 배치물과 Land는 포함하며 Land Collider는 Ground 레이어로 지정한다. 생성된 프리팹의 기존 맵 목록/Addressables 연결은 별도로 설정한다.

장애물의 활성 non-trigger Collider는 서버의 기존 XZ 축 정렬 box로 추출한다. 회전된 메시의 세밀한 충돌 형태나 다층 지형을 그대로 복제하는 형식은 아니다. 같은 목적의 Collider를 여러 개 겹치게 두면 box도 여러 개 생성된다. 몬스터·채집물 Collider와 Land는 장애물에서 제외한다.

서버 정의 파일은 `EverWindServer/LoginServer/Content/GameData.ewdata`이며 창에서 경로를 바꿀 수 있다. 존재하지 않는 정의 ID·중복 스폰 ID·경계 밖 배치·Land가 없는 위치는 추출 전에 거절한다. 기존 TXT는 임시 파일 작성 후 교체하며 이전 높이 파일은 다른 맵에서 참조할 수 있어 자동 삭제하지 않는다.
