# DB 초기화

`InitializeDatabase.sql` 하나로 현재 DB의 16개 테이블·컬럼·기본값·인덱스·외래키를 재생성한다. 현재 DB 구조에서 추출한 파일이며 과거 단계별 migration SQL은 삭제했다.

**실행 시 기존 계정·인벤토리·퀘스트·성장·기준 테이블의 모든 행이 삭제되고 자동 증가 번호도 초기화된다.** 행 데이터와 비밀번호, DB 접속 계정 생성·권한 설정은 포함하지 않는다. 실행 전에 서버를 종료한다. DDL 초기화는 전체를 트랜잭션으로 되돌릴 수 없다.

대상 DB는 SQL의 `CREATE DATABASE IF NOT EXISTS`와 `USE`에 명시되어 있다. 다른 이름으로 구성하려면 두 구문의 DB 이름을 함께 수정하고 서버 접속 설정도 맞춘다. 새 DB 생성에는 해당 권한이 필요하다. SQL 파일은 서버 시작 때 자동 실행하지 않는다.

서버 설정의 접속 계정으로 현재 DB를 초기화할 때:

```powershell
& .\EverWindServer\LoginServer\Tools\initialize-server-database.ps1 -Reset
```

`-Reset`이 없으면 실행하지 않는다. 빈 DB를 새로 생성하는 경우에는 생성 권한이 있는 계정으로 SQL 파일을 직접 실행한다. 실행 도구는 SQL 대상 DB와 서버 설정이 일치하는지도 검사한다.

초기화 직후 테이블의 데이터는 모두 비어 있다. 서버 시작 시 `Content/GameData.ewdata`와 `Content/MapData`에서 기준 데이터·맵을 읽고 `MapInfo`에 맵 ID를 등록한다. 기존 기준 테이블은 현행 DB 구조를 그대로 재현하기 위해 남겼지만 서버의 콘텐츠 원본은 파일이다. 사용자 계정은 회원가입부터 다시 만든다.

파일 생성 시 사용 중인 DB는 초기화하지 않았다. 별도 임시 MariaDB에서 구조 일치와 재실행 시 데이터 삭제를 검증했다.
