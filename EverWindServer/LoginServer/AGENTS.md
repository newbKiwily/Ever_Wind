# 서버 코드 작성 규칙

- 이 폴더의 C++ 소스와 헤더에만 적용한다. 클라이언트는 변경하지 않는다.
- 변수 선언 묶음과 함수 선언 사이에는 빈 줄을 한 줄 둔다.
- 같은 타입의 연속 변수 선언은 붙이고 타입이 바뀌면 한 줄 띈다. 지역 선언에도 이 규칙을 우선 적용한다.
- public/protected/private는 클래스마다 각각 최대 한 번 쓴다. 접근 권한은 보존한다.
- 각 접근 영역에서 타입 별칭, 멤버변수, 함수 순으로 배치한다. private 영역을 우선하며 생성 의존성이 있는 멤버의 상대 순서를 보존한다.
- 모든 설명 주석은 한글로 쓴다. namespace 종료 주석은 넣지 않는다.
- CPP 함수 정의 사이와 함수 내부의 연속 구문 사이에는 한 줄을 띈다.
- 같은 이름의 함수를 연속 호출하면 빈 줄 없이 붙인다. 서로 다른 타입의 변수 선언 규칙이 우선이다.
- 함수 선언과 호출의 파라미터는 한 줄에 쓴다. 사용자가 허용한 예외로 람다 본문만 여러 줄로 유지한다.
- 함수와 제어문의 여는 중괄호는 다음 줄에 쓴다.
- if의 본문이 바로 return이 아닌 경우 중괄호를 반드시 쓴다. 일관성을 위해 return 분기에도 중괄호를 사용할 수 있다.
- .clang-format과 Tools/format-server-style.py를 사용하되 자동 재배치 후 토큰 보존, 접근 권한, 선언 누락 및 빌드를 확인한다. 도구가 기본 인수의 중괄호 등을 함수 본문으로 오인하면 원본과 대조하고 중단한다.
